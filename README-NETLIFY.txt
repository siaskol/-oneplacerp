Деплой на Netlify

В архиве уже находится готовая статическая сборка сайта. Исходники и команда сборки не требуются.

Вариант 1 — ручная публикация:
1. Распакуйте архив.
2. Загрузите на Netlify содержимое папки сайта (папку, в которой непосредственно лежат index.html, netlify.toml и _redirects).

Вариант 2 — через Git:
1. Добавьте содержимое этой папки в корень репозитория.
2. Создайте сайт на Netlify из репозитория.
3. Build command оставьте пустой, Publish directory укажите ".".

Файл _redirects настроен для SPA: прямое открытие внутренних маршрутов возвращает index.html.
